# Construction Compliance Standards - TilTool Reference

## Overview

This document provides construction industry standards and compliance references used by TilTool.

## International Standards

### ISO 13006 - Ceramic Tiles
- Defines tile dimensions and tolerances
- Specifies quality grades
- Establishes testing procedures
- Applicable globally

### ISO 13007 - Tile Installation
- Adhesive specifications
- Grout composition requirements
- Joint width specifications (1.5-10mm)
- Substrate preparation requirements

### ANSI A108 Series (North America)
- Installation specifications
- Material standards
- Quality assurance procedures

## Tile Specifications

### Standard Tile Sizes
- Small: 50-300mm
- Medium: 400-600mm
- Large: 700-1000mm
- Extra-large: 1100-3000mm

## Grout Standards

### Recommended Joint Widths
- Minimum: 1.5mm (rectified tiles)
- Standard: 2-3mm (most common)
- Maximum: 6-10mm (without special preparation)

## Wastage Guidelines

### Recommended Percentages
- Simple Grid: 5% (minimal cuts)
- Standard/Staggered: 10% (recommended)
- Diagonal/Complex: 15-20% (maximum)

## Quality Standards

### Before Installation
- Verify samples in actual lighting
- Check batch consistency
- Inspect for defects
- Test on sample area first

### Installation Quality
- Substrate flatness: ±3mm per 3m
- Plumb tolerance: ±3mm per 3m
- Grout joint consistency: ±1mm
- Lippage (vertical variance): ±1-2mm

### After Installation
- Inspect all grout joints
- Verify tile alignment
- Check for hollow spots
- Perform water testing
- Allow proper curing time

## TilTool Compliance Checks

✓ Wastage percentage verification (5-20%)
✓ Grout width validation (1.5-10mm)
✓ Project area assessment
✓ Large project notifications
✓ Standards compliance verification
